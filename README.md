# eye-hospital-project-# Eye Hospital Management System

The Eye Hospital Management System is a Python and MySQL-based application designed to automate basic operations of an eye hospital. It allows users to manage patient information, view doctors, make appointments, check and book rooms, and generate bills based on doctor, pathology, and room charges. Python handles the application logic while MySQL is used to store and retrieve hospital data.

## Technologies Used

- Python
- MySQL
- MySQL Connector for Python

## Features

- Patient registration
- Doctor information and consultation fees
- Appointment management
- Room availability and booking
- Hospital billing
- MySQL database integration
